# Código de conducta

## En corto

Sé buena gente. Aquí se viene a programar y a ayudar.

## Un poco más

- Se aceptan críticas técnicas duras; lo que no se acepta es despreciar a la
  persona.
- Nada de acoso, insultos, discriminación por origen, identidad, religión,
  orientación o discapacidad.
- No se admite usar este proyecto para espiar a nadie ni para saltarse
  protecciones ajenas.
- Si algo va mal en un issue o PR, se corta y se sigue. Los mantenedores pueden
  cerrar lo que rompa la convivencia.

## Alcance

Aplica a issues, PRs, discusiones y cualquier espacio del proyecto.

## Contacto

Abre un issue privado o escribe al autor del repo si necesitas reportar algo
sensible.
